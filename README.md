# Contest-Subscribe

IT·데이터·AI 공모전을 매주 모아 이 저장소에 **Issue 다이제스트**로 올립니다. 저장소를 Watch하면 GitHub 알림 메일로 받아볼 수 있습니다. 별도 가입이나 메일 등록은 없습니다.

- 소스: [위비티](https://www.wevity.com), [링커리어](https://linkareer.com)
- 발송: 매주 월요일 오전 9시경 (KST)
- 내용: 공모 주제, 접수 기간, 상금, 참가 자격, 팀 구성, 제출물을 원문과 포스터에서 AI로 요약하고 원문 링크를 함께 겁니다.

## 구독하기

1. 이 저장소 우측 상단 **Watch → Custom** 선택
2. **Issues** 체크 → Apply
3. [알림 설정](https://github.com/settings/notifications)에서 Watching 항목의 **Email**이 켜져 있는지 확인

## 구독 취소

**Watch → Participating and @mentions**(또는 Ignore)로 바꾸면 됩니다.

> AI 요약은 틀릴 수 있습니다. 지원 전에 반드시 원문을 확인하세요.

봇 코드: [yeseo-bot/Contest](https://github.com/yeseo-bot/Contest)
